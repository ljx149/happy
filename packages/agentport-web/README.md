# AgentPort Web

AgentPort 浏览器客户端，使用真实 Happy 账户认证与 V2 终端授权。

## 使用流程

首次打开终端链接时创建账户，身份自动保存到浏览器 IndexedDB，并按服务器源隔离。创建完成后继续原来的终端请求，用户确认后发送加密授权。再次打开网页会用保存的身份重新认证，不需要手动输入密钥或设置解锁口令。

账户设置提供可选恢复凭据备份与本地退出。清除站点数据会删除浏览器身份。自动保存不防御同源恶意脚本；请仅在自己的设备上使用。旧版口令保护记录仍可解锁，成功后迁移为自动保存；缺少派生盐的旧记录需要恢复凭据。

页面采用分组卡片、终端授权确认与账户设置布局，使用 AgentPort 深色青绿配色。设备来自实际 API；加密设备名称尚未解密时明确标识。终端授权成功不等于设备服务已启动，也不代表聊天和远程执行功能已经交付。

## 开发

通过项目的 pnpm workspace 安装依赖。`pnpm --filter agentport-web build` 生成 dist，静态服务需要 SPA 回退并与 Happy API 使用同一源；不要直接用静态服务器运行包含 TypeScript 的源文件。服务端可通过公开配置指定 API 地址。

本次 UI 与自动保存调整尚未进行测试、构建或浏览器验收，未部署。
