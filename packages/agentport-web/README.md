# AgentPort Web UI

可交互的 AgentPort Web 前端预览。视觉沿用 [Xcoder](https://xcodex.vip/) 首页的深蓝渐变、白色胶囊按钮、深色面板和等宽代码样式。页面结构参考 Happy 原生客户端的账户恢复、设备配对、新建会话和聊天审批流程。

## 本地预览

从仓库根目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory packages/agentport-web
```

打开 `http://127.0.0.1:4173/`。创建或恢复演示账户后，可以查看设备、模拟连接第二台电脑、创建会话、发消息、批准或拒绝示例工具请求。窗口刷新会重置演示数据。

- 手机使用单列，进入会话后可返回列表。平板和桌面显示侧栏，方便切换会话。
- `index.html` 是页面入口，`style.css` 定义视觉和响应式布局，`app.js` 提供演示路由、数据和交互。前端无构建依赖。
- `/terminal/connect` 需要静态托管的 SPA 回退。联调时可用 Happy Self-host 的 `HAPPY_STATIC_DIR` 指向此目录。Python 预览服务器只验证根路径及其片段路由。

此目录使用内存中的虚拟账户和会话。演示页面不接收真实恢复密钥，终端配对、消息同步、工具审批和 Agent 执行均待接入。生产接入以 [AgentPort 实施计划](../../docs/plans/agentport-implementation-plan.md) 中的认证与 Web 兼容验证为准。

## P0 页面范围

| 页面 | 内容 |
| --- | --- |
| 登录首页 | 产品入口、创建账户、进入恢复流程 |
| 恢复账户 | 恢复流程及凭据说明 |
| 工作台 | 在线设备概览、最近会话、待审批提示 |
| 连接电脑 | CLI 入口、确认或取消配对、完成状态 |
| 设备管理 | 在线与离线状态、连接入口、撤销确认 |
| 新建会话 | 设备、项目、Agent、可选的首条消息、无在线设备状态 |
| 会话详情 | 消息、工具审批、设备不可用时的只读历史 |

审批和撤销确认属于所在页面。设备撤销、重新连接和历史只读均使用演示状态。
