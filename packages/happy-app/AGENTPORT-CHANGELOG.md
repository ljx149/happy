# 2026-11-11 · 网页 1.0.3 / CLI 1.2.12：DSH 配置检查与扫码配对

需要更新电脑端 CLI 至 1.2.12 并重启 daemon。

- 使用 DSH 前检查实际 ACP 配置中是否存在 xmodels/Xcoder1.0；未配置时显示教程入口和重新检测按钮，不能创建对话。
- 配置后解锁 DSH，不强制改变默认模型或其他模型选择；Codex、Claude Code 不受此限制。
- CLI 登录同时显示二维码和原始配对链接，手机扫码后在网页确认授权。
